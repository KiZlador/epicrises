3. Комментарии и лишний код: удалены неиспользуемые импорты и старые функции интерфейса,
   отформатированы Python-файлы. Ruff проходит без ошибок. В рабочих исходниках нет

   Тестовые имитации модели находятся только в tests/ и проверяют обработку ошибок.

   defaults test_docs → test_json; метрики отдельно в reports. Общая длительность,

   На образце контрольная сумма .json до/после запуска без модели совпала.

Реальная модель
Qwen2.5-3B Q4_K_M на Apple M4 Pro, 48 ГиБ, Metal. Сначала короткий запрос:
загрузка 9,29 с, ответ 0,47 с, пик RSS процесса 2,48 ГиБ, swap не увеличился.
После исправления схемы генерации технический запуск на одном документе:
5,07 с с загрузкой модели, без предупреждений разбора ответа.
Партия: 99/100 документов завершены, 100-й прерван пользователем.
У всех 99 результатов валидный контракт; сопоставлено 4950 полей.
4949 совпали с прежней авторской разметкой; один ответ поместил аторвастатин
в ace_ing_sartan. Добавлена защита от переноса известного препарата другого класса,
её регрессионный тест проходит. После этой защиты инференс не повторялся.
Итоговый замер всей партии не сохранился: исходный CLI писал отчёт только в конце.
Теперь Ctrl+C сохраняет отчёт; это отдельно проверено тестом.
Регулярки после исправлений: 100 документов, 5000/5000 совпадений с той же разметкой.
Разметка неофициальная, создана ранее в этой задаче и не проходила независимую
экспертную проверку. После исправлений на этих же данных это регрессионная сверка,
а не оценка качества на неизвестных документах или гарантированная точность.

Исправлено по результатам проверки
— Модель копировала структуру входного JSON. Добавлена обязательная схема только
  запрошенных выходных полей и уточнён формат ответа.
— «Сахарный диабет отрицает» принималось за наличие диагноза.
— «Первичный статус» не распознавался, и мог выбираться повторный осмотр.
— Пропускалась дата перед «выполнена селективная КАГ».
— Статин мог попадать в поле иАПФ/сартанов.
— Панель экспорта показывалась до появления результатов из-за CSS.
— Ошибка получения результата могла показываться как «ещё не обработан».
— При Ctrl+C терялся итоговый отчёт по уже начатой партии.
— Отсутствие инфаркта выдавало лишнее предупреждение вместо обычного кода N.

Интерфейс
Локальный сервер запущен, два синтетических документа загружены через браузер.
Без LLM: 2/2 обработаны, отображаются 50 полей; закрепление/снятие цитаты работает.
В консоли браузера нет ошибок. Скачивание через API проверено: JSON, ZIP, XLSX.
При нажатии «Сохранить» браузерная автоматизация не получила событие download;
сообщения об ошибке в интерфейсе нет. Сам факт сохранения файла браузером не подтверждён.

Оставшиеся ограничения проверки
— 100-й документ не завершён с LLM.
— Полный Pipeline с LLM и цитатами проверен на двух документах; массовая оценка
  полноты и смысловой корректности цитат не проводилась. HTTP/UI проверялись без LLM.
— Исправление класса лекарства проверено без повторного инференса.
— Закрытая выборка организаторов недоступна; независимая точность неизвестна.
— Длительный инференс нагревает ноутбук; пользователь попросил его остановить.
  Модель остановлена, дальнейшая проверка проводилась без неё.
